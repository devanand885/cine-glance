# 🎬 CineGlance

An all-in-one, single-screen movie intelligence dashboard. Type in any movie name, and instantly reveal its trailers, cast timelines, streaming availability, and aggregated review scores.

Built entirely using **Google Antigravity** and powered by the **TMDb API**.

## ✨ Features
* 🔍 **Smart Search:** Instant autocomplete suggestions as you type.
* 📺 **Trailers & Metadata:** Embedded YouTube trailers alongside dynamic color-matched hero sections.
* 🍿 **Streaming Hub:** Real-time localization showing exactly where to stream, rent, or buy.
* 📊 **Aggregated Scoreboard:** Side-by-side comparison of major critic ratings.
* 👥 **Interactive Cast Carousel:** Horizontal scroll of cast members and their roles.

## 🛠️ Tech Stack
* **Framework:** React (Vite)
* **Styling:** Tailwind CSS (Glassmorphism theme)
* **AI Orchestration:** Google Antigravity
* **Data Sources:** The Movie Database (TMDb) API

## 💻 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com
cd cine-glance
```

### 2. Install dependencies
```bash
npm install
```

### 3. Set up your environment variables
Create a `.env` file in the root directory and add your TMDb API key:
```env
VITE_TMDB_API_KEY=your_api_key_here
```

### 4. Run the development server
```bash
npm run dev
```
